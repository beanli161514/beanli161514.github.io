NeuroFly: a data engine for neuron reconstruction

Rubin Zhao

NeuroFly extracts neuron fragments through learning-based segmentation and automated tracing, then reformulates reconstruction as structured endpoint tasks: review a connection between fragments, select among nearby fragment endpoints, or choose a continuation point when no nearby endpoint is available. Each task pairs a small action set with local 3D image context for human or vision-language model (VLM) review. Outcomes update the neuron graph and retain reviewer attribution and status for training and evaluation.

Implementation and data

Large image volumes remain in storage; local image windows and the neuron graph define each review task. The public NeuroFly repository contains the tools for creating initial reconstruction data, one component of the data-engine workflow. This browser demo uses saved annotations from a 600 MB public sample with display-normalized 32 × 32 × 32 voxel image windows. Its point candidates are deterministic image proposals: points near local intensity maxima at an appropriate distance, guided by the endpoint direction.

Demo reviews are local and unverified. Candidate generation here does not use model inference; training is not run in the browser.
