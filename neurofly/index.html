From cold start to a data engine.

At terabyte and petabyte scale, the full image stays in storage. Local image windows and a neuron graph define the work. The public NeuroFly repository provides tools for creating initial reconstruction data; this demo explores standardized review for the next learning cycle. The examples replay saved annotations from a 600 MB public sample, using display-normalized 8-bit crops. Visitor reviews remain unverified.
